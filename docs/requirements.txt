# ==========================================
# Documentation build dependencies
# ==========================================
#
# What Sphinx needs to render these docs. Used by Read the Docs and by CI.
#
# This is NOT just the Sphinx packages. conf.py loads jupyter_sphinx, and
# several pages under source/advanced/ use `{jupyter-execute}` blocks that run
# real code at build time — so the libraries those cells import are hard build
# dependencies. Removing them does not make the build lighter, it breaks it.
#
# The root requirements.txt additionally carries tooling for working on the
# cluster (distributed, dask-jobqueue, matplotlib, seaborn, bokeh, jupyter,
# sphinx-autobuild, alternate themes). Those appear only in non-executed code
# blocks, so they are deliberately absent here.

sphinx

# refuses to start without.
